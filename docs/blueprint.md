# **App Name**: AURA Cafe Companion

## Core Features:

- Cafe Info Display: Display cafe information, including the location, hours, and a welcome message, in a visually appealing manner.
- Menu Presentation: Display a curated menu, highlighting featured items and providing essential information.
- Product Details: Provide a visually rich and informative product detail view, complete with images, descriptions, and pricing.
- Profile Management: Enable users to view and manage their profile information, order history, and saved addresses.
- AI-Powered Recommendation: Recommend new items or preparations based on previous orders, highlighting ingredients or qualities they have appreciated in the past; uses a tool for ranking various signals and properties.

## Style Guidelines:

- Primary color: Warm beige (#E0CBA8) to evoke a sense of artisanal craftsmanship and warmth.
- Background color: Light beige (#F5F0EC), subtly different from the primary, to keep the overall feel light and inviting.
- Accent color: Muted brown (#A68B72), analogous to the primary, adding depth and highlighting key elements.
- Font pairing: 'Belleza' (sans-serif) for headlines to represent the art and design space of the cafe combined with 'Alegreya' (serif) for body text for a slightly intellectual feel.
- Use line-style icons with rounded corners, reflecting the minimalist style and crafted aesthetic.
- Employ a clean and spacious layout with ample whitespace to enhance readability and create a calm, uncluttered feel.
- Use subtle transitions and animations when navigating between pages to create a smooth and engaging user experience.
